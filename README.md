# Capstone 1: EmporiUm Sales Territory Analysis

## Overview
In this project, I  will analyze sales data for EmporiUm, a student bookstore chain, using SQL and Excel.

## Territory
I am analyzing the **Maine (ME)** in-store sales territory, which is part of the **Northeast** region.

## Files
- `capar_sales_analysis.sql`: SQL queries for the territory analysis
- `capar_territory_chart.xlsx`: PivotChart of the results
